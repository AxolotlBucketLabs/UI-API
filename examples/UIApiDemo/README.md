# UI-API demo

This small Axolotl-PM plugin demonstrates the forms, sidebar and boss bar APIs
provided by UI-API.

Copy `UIApiDemo/` into the server's `plugins/` directory and make `UI-API`
available in the server's `virions/` directory. DevTools can then load the
folder plugin and shade the virion when you build it.

Run `/ui` in game to open the demo menu.
